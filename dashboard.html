✅ Cara Tambah Fitur Utama ke-6, ke-7 dst (Sekarang Cukup 1 Tempat)

1. Buka file: js/config/service-menu.js
2. Cari: const ALL_FEATURES = [ ... ]
3. Tambah object baru:
{ id: 'laporan', label: 'Laporan', icon: '📋', sub: ['Harian','Bulanan'] }
4. Tambah path di PATH_CONFIG.pages:
laporan: 'modules/laporan/index.html'
5. Selesai! Sidebar otomatis muncul, ceklis hak akses di Pengaturan otomatis muncul, tidak perlu edit dashboard.html lagi.
💡 Jika fitur lama tidak muncul setelah tambah baru, hapus localStorage users_db_v2 di browser (F12 > Application > Local Storage > Clear) agar permission baru ter-load.
